# 빅데이터로 보는 세종의 변화

시민강좌용 공식 통계 시각화. **세종특별자치시 단독** 집계이며 미래 예측이 아닙니다.

## 수록 내용
- 주민등록인구 및 연령구조: 2012~2023년 12월 말
- 총전입·총전출·순이동: 2013~2023년
- 16개 시도와 세종 사이의 이동 지도: 2023년
- 상가 유형별 공실률: 2022·2023년 4분기, 세종·전국 비교

인구·연령 자료는 행정안전부, 이동은 통계청 국내인구이동통계, 공실률은 한국부동산원 조사 수치를 국민권익위원회가 재수록한 공식 자료에서 가져왔습니다. 출처와 추출 방법은 `sources.json`, 집계값은 `sejong-data.csv`에 있습니다. 지도는 Natural Earth의 공개 지리자료입니다.

## 읽는 법
주민등록인구는 외국인을 제외합니다. 총전입·총전출 추이에는 세종 내부 이동이 포함되지만 흐름 지도에서는 제외합니다. 선은 시도 대표점을 잇는 연결선이며 실제 이동 경로가 아닙니다. 공실률은 빈 면적 비율로, 폐업률·매출·점포 개수 비율과 다릅니다. 상가 유형을 합산하거나 인과관계로 해석하지 않습니다.

## 열기
GitHub Pages: Settings → Pages → Deploy from a branch → master / root.
로컬: 이 폴더에서 `python -m http.server 8080` 후 `http://localhost:8080`.
`index.html`과 `snapshot.*.json`은 함께 배포해야 합니다.

집계 합계, 연령·성별 합계, 순이동, 시도 간 경로 합계를 검산했습니다. 원자료의 개인별 기록, 비공개 연구 결과, 모델, 인증정보는 포함하지 않습니다. 진행 중인 연구 실험과 별개입니다.

## 강좌용 그림

- `sj-pop-chart.png`: 세종 인구 증가. 주민등록인구이며 외국인은 제외합니다.
- `sj-age-share.png`: 0~14세·15~64세·65세 이상 비율 변화.
- `sj-age-detail.png`: 2023년 성별·5세 단위 연령구조.
- `sj-move-lines.png`: 총전입·총전출. 세종 내부 이동을 포함합니다.
- `sj-move-net.png`: 전입에서 전출을 뺀 순이동.
- `sj-flow-map.png`, `sj-flow-out.png`: 2023년 시도 간 전입·전출 지도.
- `sj-vacancy.png`: 상가 유형별 공실률. 매출이나 폐업률이 아닙니다.

그림 축의 K는 천 명입니다(예: 15K = 1만 5천 명). 모든 그림에 출처를 표시했습니다. `sejong-lecture.html`은 인터넷 없이 열 수 있는 단일 파일입니다. 웹페이지의 CSV 다운로드에는 같은 폴더의 CSV 파일이 필요합니다.
